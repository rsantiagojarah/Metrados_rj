# Fase — cálculo de una partida

> Fecha: 2026-09-25 · Límite único de este ciclo

Este ciclo abre un solo módulo: el contexto de cálculo de una partida.

Dentro: una partida, sus dimensiones y la cantidad que resulta de ellas.

Fuera, y por tanto sin código en este ciclo: la plantilla PySide6, el enlace PyO3, la persistencia, el empaquetado con Maturin y cualquier catálogo de fórmulas por unidad de medida.
